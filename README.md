## 🚀 Featured Projects

### 🏥 [Smart Health Platform](https://github.com/bahaeddine-krifa/smarthealth-platform)
A healthcare management platform split into **9 gRPC microservices** (patients, doctors, appointments, medical records, payments, inventory, laboratory, notifications, alerts), exposed through a Node.js **API Gateway** with REST and GraphQL, and connected by **Apache Kafka** events. Team project.

**Tech:** Node.js • gRPC • GraphQL • Apache Kafka • React • Tailwind CSS • SQLite • RxDB • Docker Compose

### 🎓 ENISO-LEARNING &nbsp;·&nbsp; [Frontend](https://github.com/bahaeddine-krifa/FE_E-learning) | [Backend](https://github.com/bahaeddine-krifa/BE_E-learning)
An educational web platform for ENISo: teachers publish and manage course materials, students download resources and follow updates, with a **real-time WebSocket chat** and a **chatbot powered by the Google Gemini API**.

**Tech:** Angular • Angular Material • Spring Boot • MySQL • WebSocket • Gemini API

### 🚁 [Intelligent Quadcopter Drone](https://github.com/bahaeddine-krifa/smart-quadcopter-drone-esp32)
An autonomous quadcopter with ESP32 flight control, PID stabilization, GPS and telemetry, controlled over **ESP-NOW** with automatic return on signal loss, plus a C# flight-monitor desktop app.

**Tech:** ESP32 • ESP-NOW • C++ • C# • GPS

### 🚸 [AR Road-Sign Recognition](https://github.com/bahaeddine-krifa/Unity-Vuforia-Road-Sign-Recognition-AR)
An augmented reality app that recognizes street-sign plaques through the camera and plays a short educational video about road signs.

**Tech:** Unity • Vuforia
